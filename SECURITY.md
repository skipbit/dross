# Security Policy

## Supported Versions

dross has no release yet. Security fixes are made on the `main` branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues or pull
requests.

Report them privately through GitHub instead: open the **Security** tab of this
repository and choose **Report a vulnerability**
(<https://github.com/skipbit/dross/security/advisories/new>). The report stays
private until an advisory is published.
